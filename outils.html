🛡️ Testeur de mot de passe

    Ce test se fait sur ton téléphone : le mot de passe n'est ni envoyé ni enregistré. N'y écris pas un mot de passe que tu utilises vraiment : teste plutôt un exemple du même genre. L'estimation est indicative.

    #️⃣ Empreintes SHA (hash)

    Une empreinte identifie un texte sans le révéler : le moindre changement donne une empreinte totalement différente. Ce n'est pas du chiffrement. SHA-1 est vieilli : préfère SHA-256 ou SHA-512. Dans une vraie application, on ne stocke pas les mots de passe avec un simple SHA.

    💾 Convertisseur d'octets

    Les fabricants de stockage utilisent le système décimal ; les systèmes d'exploitation affichent souvent le binaire, d'où les petites différences de capacité.

    🌐 Calculatrice réseau (IPv4)

    Le préfixe (par exemple /24) indique combien de bits appartiennent au réseau. Plus il est grand, plus le réseau est petit.
